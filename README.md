# 📊 PowerPoint Web - Suite Completa & Editor Presentazioni

Benvenuto nel repository di **PowerPoint Web**, un'applicazione web interattiva, leggera e potente creata per progettare slide, comporre documenti e gestire presentazioni animate direttamente dal tuo browser! Il progetto è interamente racchiuso in un unico file combinato (HTML, CSS e JavaScript), facilitando la massima portabilità senza necessità di installazioni complesse o server.

---
🖱️ Aggiungi testi, disegna forme, carica immagini e trascina gli elementi per comporre le tue slide!

## 🚀 Funzionalità Principali (Spiegate Semplici)

### ✏️ 1. Strumenti di Creazione e Modifica
* **Caselle di Testo (T):** Inserisci blocchi di testo flottanti. Puoi spostarli liberamente, modificarne il colore e regolarne la grandezza.
* **Forme Geometriche (🟡):** Aggiungi elementi vettoriali come quadrati, cerchi, triangoli e semicerchi. Puoi colorarli o riempirli ritagliando un'immagine personalizzata (Image Fill)!
* **Immagini (🖼️):** Carica foto dal tuo dispositivo, ridimensionale tramite un comodo slider e posizionale esattamente dove vuoi.
* **Gestione Livelli (⬆️/⬇️):** Porta in primo piano o manda in secondo piano testi, forme e foto grazie ai comandi rapidi su ogni elemento.

### 📐 2. Canvas, Formati e Precisione
* **Formati Foglio Modificabili:** Scegli al volo il layout ideale per il tuo lavoro: **Slide 16:9** per monitor, **A4** o **A3** per la stampa, oppure inserisci dimensioni **Custom** espresse in pixel.
* **Sistema Drag & Drop:** Clicca su "✥ Muovi" sopra gli elementi selezionati per trascinarli in tempo reale sulla griglia di lavoro.

### 🎬 3. Gestione Slide e Animazioni
* **Barra Laterale Slide:** Aggiungi nuove slide vuote, eliminale o riordinale spostandole su e giù nella scaletta.
* **Motore Transizioni (✨):** Imposta effetti di passaggio spettacolari tra una slide e l'altra scegliendo tra: *Dissolvenza*, *Quadretti (Pixelate)*, *Spirale* o *Nessuna*.
* **Avvia Presentazione (▶):** Entra in una vera modalità cinema a tutto schermo per riprodurre in sequenza il tuo progetto, completa di menu a comparsa laterale per saltare a slide specifiche.

### 💾 4. Salvataggio ed Esportazione
* **Esporta in PDF (📄):** Unisci automaticamente tutte le slide in un unico documento PDF pronto per la stampa o la condivisione via email.
* **Salva Singola Slide (🖼️):** Scarica la slide che stai visualizzando come un'immagine PNG ad alta risoluzione.
* **Salvataggio Progetto JSON (💾 / 📂):** Esporta l'intero file di lavoro in formato dati per metterlo al sicuro, per poi ricaricarlo successivamente e riprendere da dove avevi interrotto.

---

## 💻 Come Usare l'Applicazione

1. **Apertura:** Scarica il file `presentazione_11.html` sul tuo computer.
2. **Nessuna Configurazione:** Fai doppio clic sul file per aprirlo in un qualsiasi browser web moderno (Chrome, Edge, Firefox, Safari).
3. **Uso Offline:** Il codice funziona completamente offline eccetto per la conversione in PDF. aprire in VS Code con Live Server o simili scaricando e tenendo nella stessa cartella il file "https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js". (I salvataggi JSON e l'esportazione PNG avvengono localmente).

---

## 📽️ Modalità Presentazione e Condivisione

Per mostrare il tuo lavoro o esportarlo per i colleghi:

1. **Riproduzione Diretta:** Clicca su `▶ Avvia Presentazione`. Usa le frecce a schermo o clicca col mouse per scorrere tra le diapositive ammirando le **Transizioni** impostate per ogni scena.
2. **Esportazione in PDF:** Una volta ultimato il lavoro, assicurati di aver disposto correttamente gli elementi nel canvas scelto (es. 16:9), quindi clicca su `📄 PDF`. Il sistema genererà un file a pagine contenente l'intero mazzo di slide.
3. **Backup del Lavoro:** Usa sempre il tasto `💾 Salva` prima di chiudere il browser per non perdere le modifiche. Verrà scaricato un file `.json` che potrai re-importare dal tasto `📂 Carica`.

# 📊 PowerPoint Web - Full Suite & Presentation Editor

Welcome to the repository for **PowerPoint Web**, an interactive, lightweight, and powerful web application designed to craft slides, compose documents, and manage animated presentations directly from your browser! The project is completely self-contained in a single combined file (HTML, CSS, and JavaScript), making it highly portable with no complex installation or servers required.

---
🖱️ Add texts, draw shapes, upload images, and drag elements to compose your slides!

## 🚀 Key Features (Explained Simply)

### ✏️ 1. Creation & Editing Tools
* **Text Boxes (T):** Insert floating text blocks. You can move them freely, change their color, and adjust the font size.
* **Geometric Shapes (🟡):** Add vector elements like squares, circles, triangles, and semicircles. You can color them or fill them by clipping a custom image inside!
* **Images (🖼️):** Upload photos from your device, resize them using a convenient slider, and position them exactly where you want.
* **Layer Management (⬆️/⬇️):** Bring texts, shapes, and photos to the front or send them to the back using quick controls attached to every element.

### 📐 2. Canvas, Formats & Precision
* **Adjustable Sheet Formats:** Choose on the fly the perfect layout for your work: **Slide 16:9** for screens, **A4** or **A3** for printing, or enter **Custom** pixel dimensions.
* **Drag & Drop System:** Click on "✥ Muovi" (Move) above selected elements to drag them around your workspace in real-time.

### 🎬 3. Slide Management & Animations
* **Slide Sidebar:** Add new blank slides, delete them, or reorder them by moving them up and down the list.
* **Transition Engine (✨):** Set stunning transition effects between slides by choosing from: *Fade*, *Blocks (Pixelate)*, *Spiral*, or *None*.
* **Start Presentation (▶):** Enter a true full-screen cinematic mode to play your project in sequence, complete with a slide-out sidebar menu to jump to specific slides.

### 💾 4. Saving & Exporting
* **Export to PDF (📄):** Automatically merge all your slides into a single multi-page PDF document ready for printing or email sharing.
* **Save Single Slide (🖼️):** Download your currently viewed slide as a high-resolution PNG image.
* **JSON Project Saving (💾 / 📂):** Export your entire workspace data as a file to keep it safe, then load it back later to pick up right where you left off.

---

## 💻 How to Use the Application

1. **Opening:** Download the `presentazione_11.html` file to your computer.
2. **Zero Configuration:** Double-click the file to open it in any modern web browser (Chrome, Edge, Firefox, Safari).
3. **Offline Use:** The code works completely offline except for the PDF conversion. Open in VS Code with Live Server or similar by downloading and keeping the file "https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js" in the same folder.

---

## 📽️ Presentation Mode & Sharing

To showcase your work or export it for colleagues:

1. **Direct Playback:** Click on `▶ Avvia Presentazione` (Start Presentation). Use the on-screen arrows or click with your mouse to navigate through the slides, enjoying the **Transitions** configured for each scene.
2. **PDF Export:** Once your work is finished, make sure you have properly arranged the elements in your chosen canvas format (e.g., 16:9), then click on `📄 PDF`. The system will generate a paginated file containing the entire slide deck.
3. **Workspace Backup:** Always use the `💾 Salva` (Save) button before closing the browser to prevent data loss. It will download a `.json` file that you can re-import using the `📂 Carica` (Load) button.
